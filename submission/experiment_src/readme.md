# Experiment Scripts

Standalone scripts for running each method on each task.

## Planar Arm
- `PlanarArm_MAPElites.py` — MAP-Elites (Gaussian mutation and mutation+line variants).
- `PlanarArm_CMAME.py` — CMA-ME.
- `PlanarArm_LVE.py` — LVE without auxiliary loss.
- `PlanarArm_BehavePred.py` — LVE + BehavePred.

## Ant-v5 Environment for Unidirectional Locomotion
- `AntGaitUni_MAPElites.py` — MAP-Elites.
- `AntGaitUni_CMAME.py` — CMA-ME.
- `AntGaitUni_LVE.py` — LVE without auxiliary loss.
- `AntGaitUni_BehavePred.py` — LVE + BehavePred.
