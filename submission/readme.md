# Behavior-Aware Representation Learning for Quality-Diversity Latent Variable Evolution

Source code for the paper "Behavior-Aware Representation Learning for Quality-Diversity Latent Variable Evolution" (Group ID: 16).

## Structure

- `src/` — Core library implementing the QD-LVE framework and BehavePred.
- `experiment_src/` — Standalone scripts for each method and task (Planar Arm, Ant-v5).
- `experiment_notebooks/` — Jupyter notebooks reproducing all experiments and analysis.

Each subdirectory contains its own `readme.md` with further details.
